# «Планета — кабинет» и «Планета — касса» — вход с телефона

Две обложки-приложения на том же GitHub Pages, что и «Отметки» для преподавателей. Внутри — обычный журнал с сервера, ничего на телефоне не хранится, работает только онлайн.

| Иконка | Адрес | Кто | Что открывается |
|---|---|---|---|
| **Кабинет** | https://osoobilim3.github.io/app/kabinet.html | руководитель, кассир, ресепшн, учебная часть | экран входа «Сотрудник → код доступа»; роль определяется кодом |
| **Касса** | https://osoobilim3.github.io/app/kassa.html | кассир | сразу касса (`…/exec?page=kassa`) в телефонном режиме — приём оплаты, чеки из WhatsApp, зачёты, должники |
| Отметки | https://osoobilim3.github.io/app/ | преподаватели | журнал отметок (как раньше) |

## Как добавить на экран телефона (один раз)

**iPhone (Safari):** открыть адрес → кнопка «Поделиться» (квадрат со стрелкой) → «На экран «Домой»» → «Добавить».
**Android (Chrome):** открыть адрес → меню «⋮» → «Добавить на главный экран» (или «Установить приложение») → «Добавить».

Дальше приложение открывается значком, на весь экран. Код доступа вводится при каждом открытии — на телефоне он не хранится.

## Если не открывается

- «Проверьте интернет» — нет связи; нажать «Повторить».
- Открывается долго — подождать (Google грузит журнал дольше обычного сайта) или нажать «Открыть в браузере».
- Файлы обложки: `kabinet.html` + `kabinet.webmanifest`, `kassa.html` + `kassa.webmanifest`, значки `icons/kabinet-*.png`, `icons/kassa-*.png`; адрес журнала — строка `JOURNAL_URL` в каждом файле (тот же, что в `index.html`; у кассы с хвостом `?page=kassa`).
